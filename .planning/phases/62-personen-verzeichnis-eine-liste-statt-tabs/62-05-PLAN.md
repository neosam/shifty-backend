## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → HTTP-Endpoint | Untrusted: jeder authentifizierte Nutzer kann den Pfad direkt aufrufen, unabhaengig davon, was das Frontend anzeigt. |
| Endpoint → Business-Logic-Service | Der Handler reicht den Session-Kontext durch; das Gate liegt im Service. |
| Dev-Proxy (`dx serve`) → Backend | Nur Entwicklungszeit; ohne Eintrag liefert der Dev-Server 404/405 statt der Liste. |

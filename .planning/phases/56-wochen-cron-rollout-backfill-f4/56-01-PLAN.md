<key_finding>
CRITICAL context for the neutrality tests (verified in reporting.rs:185-198, 856, 1187, 1726, 2156): Phase 55 (D-55-A1) ALREADY filters `source == ExtraHoursSource::Manual` at every read-aggregation entry point (assemble_weeks, get_reports_for_all_employees, hours_per_week, overall_extra_work_hours). Rebooking-source ExtraHours are therefore invisible to Balance, F1-Ist, F2-Soll, weekly-summary, and billing_period_report (which consumes reporting_service.get_report_for_employee_range) REGARDLESS of any toggle. This is precisely what makes D-01 provable: rebooking pairs never enter any aggregation, so a straddling billing period MUST be byte-identical. The neutrality tests assert this existing property empirically; they should pass on first RED-turned-GREEN because the machinery already exists. If any neutrality or straddling assertion FAILS, that is a real discovery (a chain leaks rebooking rows) — surface it, do not paper over it, because it flips D-01 to a version bump.
</key_finding>

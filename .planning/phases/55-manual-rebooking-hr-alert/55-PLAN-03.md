# 55-03: Property Test — Rebooking Roundtrip Neutralitaet

## Objective
Implement property test that verifies rebooking operations maintain balance, voluntary ist, and voluntary soll in reporting aggregates.

## Read First
- `.planning/phases/55-manual-rebooking-hr-alert/55-CONTEXT.md`
- `service_impl/src/test/` directory (to understand existing test structure)
- `service_impl/src/reporting.rs` (to understand reporting calculations)
- `service_impl/src/voluntary_stats.rs` (to see how voluntary stats works)

## Acceptance Criteria
- [ ] Property test created verifying that manual rebooking operations maintain:
  - `balance_before == balance_after` 
  - `voluntary_ist_before == voluntary_ist_after`
  - `voluntary_soll_before == voluntary_soll_after`
- [ ] Test uses real database interactions (integration test)
- [ ] Test demonstrates the rebooking pair of extra hours properly neutralizes in reporting
- [ ] Test covers both manual booking directions: VolunteerWork → ExtraWork and ExtraWork → VolunteerWork
- [ ] Test covers the case where approval happens and rejects are handled properly

## Action
1. Create new test file in `service_impl/src/test/` named `rebooking_neutralization_test.rs`
2. Implement property test using existing test structure patterns:
   - Set up a test scenario with an employee having voluntary hours 
   - Record balance, voluntary ist, and voluntary soll before rebooking
   - Perform manual rebooking operation (both directions)
   - Verify the values remain unchanged after the operation
3. Make sure test uses real database connections to validate the actual reporting behavior  
4. Test both approaches: 
   - Rebooking from VolunteerWork → ExtraWork
   - Rebooking from ExtraWork → VolunteerWork
5. Validate that rejected suggestions also preserve data integrity (no changes)

# 55-04: Frontend Components + Loader + State Management

## Objective
Implement all frontend components, loaders and state management necessary for manual rebooking and HR alert features.

## Read First
- `.planning/phases/55-manual-rebooking-hr-alert/55-CONTEXT.md`
- `shifty-dioxus/src/loader.rs` (existing loader structure)
- `shifty-dioxus/src/component/` directory (existing component patterns)
- `shifty-dioxus/src/page/employees.rs` (employee overview page)  
- `shifty-dioxus/src/page/employee_details.rs` (employee detail page)

## Acceptance Criteria
- [ ] New frontend components created:
  - `rebooking_alert_banner.rs` for displaying HR alerts
  - `rebooking_suggestion_modal.rs` for suggestion display and approval/rejection
  - `manual_rebooking_modal.rs` for manual rebooking operations
- [ ] New state mapper created in `shifty-dioxus/src/state/rebooking.rs`
- [ ] New loader functions added to `shifty-dioxus/src/loader.rs`:
  - `submit_manual_rebooking`
  - `load_rebooking_suggestions_pending`
  - `approve_rebooking_suggestion` 
  - `reject_rebooking_suggestion`
- [ ] Banner integration in `shifty-dioxus/src/page/employees.rs`  
- [ ] F3 trigger integration in `shifty-dioxus/src/page/employee_details.rs`
- [ ] Dioxus.toml updated with required proxy entries
- [ ] i18n labels added for all new UI elements

## Action
1. Create component files:
   - `shifty-dioxus/src/component/rebooking_alert_banner.rs` - displays HR alert banner for employees
   - `shifty-dioxus/src/component/rebooking_suggestion_modal.rs` - shows suggestion modal with IST/DANN columns and approve/reject buttons
   - `shifty-dioxus/src/component/manual_rebooking_modal.rs` - handles manual rebooking form with week selection, direction choice, and preview

2. Create new state mapper file:
   - `shifty-dioxus/src/state/rebooking.rs` - thin mapper from TO to component state

3. Add loader functions to `shifty-dioxus/src/loader.rs`:
   - Implement all 4 new functions that call the backend REST endpoints
   - Follow existing patterns for error handling and loading states

4. Integrate components:
   - Add banner to employee overview page in `shifty-dioxus/src/page/employees.rs`  
   - Add F3 button to employee detail page in `shifty-dioxus/src/page/employee_details.rs`

5. Update `shifty-dioxus/Dioxus.toml` to add proxy entries:
   - `/rebooking`
   - `/rebooking-suggestions`

6. Update i18n files with translations:
   - Add all required labels for modal headers, buttons, and banner text in en.ftl, de.ftl and cs.ftl
